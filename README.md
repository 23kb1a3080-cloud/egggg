# QuickBite — Ultra-Fast Food Delivery Platform

A modern, startup-style food delivery web application built for speed, real-time tracking, and seamless ordering from nearby top restaurants.

![QuickBite Preview](https://images.unsplash.com/photo-1504674900247-0877df9cc836?auto=format&fit=crop&w=1200&q=80)

---

## 🚀 Key Features

- **⚡ Blazing Fast Ordering**: Estimated delivery times (< 25 min) calculated for every nearby kitchen.
- **🛵 Live GPS Order Tracking**: Animated route simulator with real-time status stepper (`Order Placed` → `Kitchen Preparing` → `Driver Picked Up` → `Out for Delivery` → `Delivered`), courier contact info, and ETA countdown.
- **🍽️ Rich Restaurant & Dish Discovery**: Filter by cuisines (Pizza, Burgers, Sushi, Healthy Bowls, Tacos, Desserts), search dish titles, toggle dietary preferences (Vegetarian only).
- **🛍️ Interactive Cart & Customization**: Dish modal for spice levels and custom chef instructions; slide-over cart drawer with persistent `localStorage` storage.
- **🏷️ Discount System**: Working promo codes (`QUICKBITE20` for 20% off, `FREESHIP` for zero delivery fee).
- **💳 1-Click Simulated Checkout**: Delivery address selector, courier drop-off instructions, tip options, and sandbox payment methods (Apple Pay, Card, Cash on Delivery).

## 🎨 Design System

- **Primary Color:** `#FF6B35` (Vibrant Startup Orange)
- **Secondary Color:** `#202124` (Dark Charcoal)
- **Background Color:** `#FFFDF9` (Warm White)
- **Typography:** Inter Sans-Serif via Google Fonts
- **Aesthetics:** Rounded cards, soft drop shadows, glassmorphism headers, micro-animations, and high-resolution food photography.


```bash

```

### 3. Build for production
```bash
npm run build
```
